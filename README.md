## 🛡️ プロジェクト理念
昨今、サポートが切れた古いPHP環境（PHP 8.1以前EOL）や設定不備、EC-CUBE等の改ざんによるクレジットカード情報漏洩が急増しています。多くの現場が「セキュリティに高額な費用が払えない」と悩む中、SECURDIAGは営利目的の押し売りを一切行わず、有志ホワイトハッカーとして誰でも使えるセルフ診断ツールと修正パッチを完全無償公開しています。
